Despliegue y configuración

Puesta en marcha del servicio, registro del router y configuración de los usuarios.

Archivos de configuración

El repositorio original incluye una carpeta config/ con ejemplos de configuración. Consulta esos archivos para ver los parámetros exactos utilizados.

Abrir carpeta config en GitHub ↗

Estado del servicio

El servicio FreeRADIUS se encuentra operativo y muestra el mensaje:

Ready to process requests.

Configuración aplicada

  1. El router fue registrado como cliente RADIUS en clients.conf.
  2. Se configuraron los usuarios juan y maria en el archivo users.
  3. En el TP-Link TL-WR840N se configuró WPA2-Empresarial apuntando a 192.168.0.102:1812.
  4. En Android se seleccionó PEAP / MSCHAPv2 y se utilizó la identidad juan.

Resultado registrado

✓
Cliente Android conectado

La identidad juan aparece con estado Conectado.

Los parámetros anteriores corresponden a la información documentada en el README del repositorio.
