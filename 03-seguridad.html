El repositorio incluye un script de referencia: config/firewalld-centos.sh ↗.

Configuración de SELinux

  • SELinux debe permanecer en modo Enforcing.
  • No se debe desactivar con setenforce 0.
  • Restaurar etiquetas de configuración con restorecon -Rv /etc/raddb.
  • Consultar bloqueos recientes con ausearch -m avc -ts recent.
  • Para FTP hacia el directorio web, el README referencia el contexto public_content_rw_t mediante semanage fcontext y restorecon.

Estado del firewall del laboratorio

Nota importante

El README indica que el firewall del laboratorio en Kali tenía políticas en ACCEPT y no tenía reglas. Se recomienda endurecer la configuración en un entorno de producción.
