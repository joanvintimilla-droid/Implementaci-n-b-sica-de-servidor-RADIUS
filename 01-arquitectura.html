01 / FUNDAMENTOS

Arquitectura y requisitos

Cómo se conectan el cliente, el punto de acceso y el servidor de autenticación.

CLIENTEAndroidUsuario: juan
EAP-PEAP →
NAS / ROUTERTP-Link TL-WR840N192.168.0.1
RADIUS UDP →
SERVIDORFreeRADIUS192.168.0.102

El router delega la validación de los usuarios en el servidor RADIUS. El servidor responde con Access-Accept o Access-Reject. El servidor NTP utiliza UDP 123 para sincronizar la hora.

Componentes

ComponenteDetalle
ServidorFreeRADIUS 3.2.10 (laboratorio en Kali; perfil de producción: CentOS).
NASTP-Link TL-WR840N, WPA2-Empresarial, AES.
ClienteAndroid, PEAP + MSCHAPv2.

Requisitos previos

  • Dirección IP fija para el servidor.
  • Puertos UDP 1812 y 1813 abiertos hacia el router.
  • Hora del servidor sincronizada mediante NTP.
  • Secreto compartido idéntico en el router y en el servidor.
  • Al menos dos usuarios configurados.
Importante

La IP del servidor documentada es 192.168.0.102 y la IP del router/NAS es 192.168.0.1.
